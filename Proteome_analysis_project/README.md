# Proteome Analysis

Small educational R project for proteome-based data analysis. The goal is to explore how amino acid composition in prokaryotic proteomes relates to thermal adaptation.

## Structure

- `data/` - input files and downloaded resources
- `scripts/` - R scripts for analysis steps
- `results/` - CSV output tables
- `reports/` - Quarto reports and figures

## Tools and style

This project uses simple, readable R code with:

- **tidyverse** for data handling
- **ggplot2** for plotting
- **Quarto** for reporting

## Notes

- UniProt download instructions are in [`uniprot_howto.md`](./uniprot_howto.md)
- Keep code short, clear, and functional
